# DART 기업 분석

한 번에 한 회사를 다룬다. 기준과 근거 규칙은 프로젝트 루트의 `원칙.md`가 정본이다. 작업 전에 읽는다.

스크립트는 `.claude/skills/dart-analyst/scripts/`에 있고, 프로젝트 루트에서 `py`로 실행한다 (`python` 명령은 이 PC에서 동작하지 않는다). 외부 패키지는 필요 없다.

## 모드 판단

- **분석 요청** ("○○ 분석해 줘"): 아래 1~5단계를 모두 진행한다.
- **질의** ("○○의 △△는?"): `data/국내/` 또는 `data/해외/`에 그 회사 폴더가 있으면 바로 질의 모드로 간다. 없으면 먼저 1단계로 수집할지 묻는다.

## 1. DART 수집

```
py .claude/skills/dart-analyst/scripts/dart_fetch.py <회사명|종목코드>
```

- 최근 정기보고서 8건의 재무 숫자와 원문을 `data/국내/<종목코드>_<회사명>/dart/`에 저장하고 `quarters.json`(분기별 매출액·영업이익)을 만든다.
- 이미 받은 보고서는 다시 받지 않는다(접수번호가 같으면 생략).
- 종료 코드 2와 "여러 회사가 해당됩니다"가 나오면 후보를 보여 주고 어느 회사인지 묻는다. 짐작해서 고르지 않는다.
- 12월 결산이 아니라는 오류가 나오면 그대로 알리고 멈춘다.

## 2. FnGuide 조회 (외부 예외)

```
py .claude/skills/dart-analyst/scripts/fnguide_fetch.py <회사명|종목코드>
```

- 종가, FY1 컨센서스(EPS·BPS), 업종 PER·PBR을 `fnguide/<오늘 날짜>.json`에 저장한다.
- 실패하면(페이지 구조 변경, 컨센서스 없음 등) 추측하지 말고 오류를 알린다. 기준 3은 `판정 불가`가 된다.

## 3. 판정

```
py .claude/skills/dart-analyst/scripts/analyze.py <회사명|종목코드>
```

- `분석/<오늘 날짜>.md`와 `.json`을 저장한다. 판정은 스크립트가 한다. 숫자를 직접 다시 계산하거나 판정을 바꾸지 않는다.

## 4. 구글 드라이브 자료 확인

```
py .claude/skills/dart-analyst/scripts/drive_search.py <회사명> [<영문명·약칭> ...]
```

- 드라이브 자료 폴더(`G:\내 드라이브\Chrome에서 저장됨`)에서 파일명과 PDF 본문을 검색한다. 처음 실행 때는 PDF 텍스트 추출로 몇 분 걸린다(이후 캐시 사용). 오래 걸리면 백그라운드로 실행한다.
- 회사명은 DART 이름, 영문명, 약칭을 함께 넣는다(예: `ISC 아이에스시`). 파일명이 `[회사명]제목.pdf`인 증권사 리포트와 회사 IR 자료를 우선 본다.
- 찾은 자료의 핵심(실적, 가이던스, 추정치, 투자 포인트)을 판정 결과와 함께 요약하고, 문장마다 `[드라이브/파일명 p.쪽]`으로 출처를 붙인다. DART 숫자와 다르면 차이를 밝힌다.
- 드라이브 폴더가 없으면(앱 로그아웃 등) 그 사실을 알리고 나머지는 계속한다.

## 5. 결과 전달

- 스크립트가 출력한 요약 표(기준별 판정, 핵심 수치)와 종합 결과를 보여 준다.
- 기준 3의 한계(업종 값은 과거 실적 기준)를 한 줄로 함께 알린다.
- 분석 보고서 파일 경로를 링크로 준다.
- 투자 권유나 매수·매도 의견은 덧붙이지 않는다.

## 질의 모드

근거는 `data/<종목코드>_<회사명>/` 아래 파일과 구글 드라이브 자료 폴더뿐이다. 드라이브는 4단계의 `drive_search.py`로 검색하고, 찾은 PDF는 Read로 읽거나(짧은 파일) `data/_cache/drive_text/`의 추출 텍스트를 읽는다.

| 파일 | 내용 |
|---|---|
| `dart/원문/<연도>_<보고서>.txt` | 보고서 원문 전체. `#`·`##`·`####` 줄이 목차 제목이다 |
| `dart/quarters.json` | 분기별 매출액·영업이익과 산출 근거 |
| `dart/재무_<연도>_<보고서>.json` | OpenDART 전체 재무제표 원자료 (재무상태표·손익·현금흐름) |
| `dart/reports.json` | 보고서 목록, 접수번호, DART 링크 |
| `분석/<날짜>.md` | 판정 보고서 |
| `fnguide/<날짜>.json` | 주가·컨센서스·업종 값 (조회 시각 포함) |
| `메모/` | 사용자가 넣은 자료 |

절차:

1. 질문의 핵심어로 위 파일을 검색한다(Grep). 원문은 크므로 전체를 읽지 말고, 찾은 위치 앞뒤와 가장 가까운 목차 제목을 읽는다.
2. 여러 보고서에 걸친 질문이면 최신 보고서부터 확인하고, 시점을 밝힌다.
3. 답의 **문장마다** 원칙.md 3절 형식으로 출처를 붙인다.
4. 찾지 못하면 정확히 이렇게 답한다: **"DART 정기보고서와 로컬 파일에서 찾을 수 없습니다."** 일부만 찾았으면 찾은 부분만 출처와 함께 답하고, 나머지는 찾을 수 없다고 밝힌다.
5. 웹 검색이나 사전 지식으로 빈칸을 채우지 않는다. 최신 주가 등 FnGuide 값이 필요하면 2단계를 다시 실행할지 묻는다.
